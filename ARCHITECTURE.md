# Архітектура проєкту

Проєкт залишається Vue 3 SPA на Vite, але використовує зрозумілі Nuxt-подібні конвенції: `pages`, `layouts` і `plugins`. Це дає передбачувану структуру без міграції на Nuxt та зміни поточного способу публікації на GitHub Pages.

## Потік застосунку

```text
main.js
  └── plugins/ (Pinia, i18n, router)
      └── App.vue
          └── layouts/default.vue
              └── RouterView
                  └── pages/*
                      └── components/*
```

## Відповідальність директорій

| Директорія | Відповідальність |
| --- | --- |
| `src/app/router` | Маршрути, метадані сторінок і поведінка навігації. Компоненти сторінок завантажуються ліниво з `pages`. |
| `src/pages` | Компоненти верхнього рівня для маршрутів. Вони компонують секції, але не містять спільну інфраструктурну логіку. |
| `src/layouts` | Спільний каркас: header, main-контент, mobile navigation та фонові елементи. |
| `src/plugins` | Єдина точка підключення Pinia, Vue I18n і Vue Router до застосунку. |
| `src/components` | Повторно використовувані UI-компоненти, згруповані за функціями: `base`, `home`, `portfolio` тощо. |
| `src/composables` | Повторно використовувана реактивна логіка без прив'язки до конкретної сторінки. |
| `src/stores` | Глобальний стан Pinia. Локальний стан компонента сюди переносити не потрібно. |
| `src/services` | Зовнішні запити та інтеграції API. UI-компоненти не повинні напряму знати деталі API. |
| `src/data` | Статичний контент портфоліо: профіль, технології, проєкти та послуги. |
| `src/i18n` | Переклади всього видимого користувачу тексту. |

## Правила залежностей

- `pages` компонують `components` і викликають `composables` або `stores`.
- `components` не імпортують сторінки чи layout-компоненти.
- API-виклики проходять через `services`.
- Контент портфоліо зберігається в `data`, а не дублюється у шаблонах.
- Глобальні плагіни підключаються лише через `installPlugins()`.
- Назва файла в `pages` відповідає маршруту: `about.vue` → `/about`, `index.vue` → `/`, `[...path].vue` → усі невідомі адреси (404).

## Як додати сторінку

1. Створити `src/pages/<route>.vue`.
2. Додати запис маршруту в `src/app/router/index.js` через `page('<route>.vue')`.
3. Додати назву маршруту до `src/i18n/messages/uk.js` та `en.js`.
4. Якщо сторінка доступна з меню, додати пункт у `src/data/navigation.js`.
5. Перевірити `npm run lint`, `npm test` і `npm run build`.
